# ☕ Brewly

Mobilní aplikace pro komunikaci mezi zákazníkem a kavárnou, objednávání a správu rezervací. Vytvořeno ve Flutter + Firebase.

## Funkce

* Přihlášení přes email/heslo nebo Google
* Role návštěvník / zákazník / obsluha
* Prohlížení menu a kategorií
* Objednávání jídla a nápojů ke stolu
* QR kód pro rozpoznání konkrétního stolu
* Přivolání obsluhy
* Rezervace stolů
* Historie objednávek
* Oblíbené produkty
* Věrnostní systém

## Technologie

* Flutter
* Dart
* Firebase Authentication
* Cloud Firestore
* Firebase Storage
* Google Sign-In
* QR kódy
